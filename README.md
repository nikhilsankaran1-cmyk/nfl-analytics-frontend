# NFL Analytics Dashboard

A React frontend for the NFL Analytics platform.

## Pages
- Teams - offensive tendencies, EPA efficiency, passing leaders for any team and season
- Games - scores and results by week
- Win Probability - interactive graph showing win probability throughout any game
- 4th Down Calculator - enter any game situation and get an analytics-based recommendation
- 2026 Simulator - Super Bowl and playoff odds from 10,000 Monte Carlo simulations

## Tech Stack
- React
- Recharts (data visualization)
- Axios (API calls)

## Setup
npm install
npm start

Runs on http://localhost:3000. Requires the Spring Boot API running on port 8080.
